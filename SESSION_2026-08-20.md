### Step 2 — Flaky test fixed (commit de77d54)

- Symptom: `test/phase4.test.mjs` failed ~1 in 5 runs with
  `AssertionError: two upgrades after two levels (1 !== 2)` at line 188.
- Root cause (from the captured failing log): NOT a timing race. The
  queued-level-ups test asserted `upgrades.size === 2` after two picks, but
  `rollUpgrades` is seeded per session (`hashSeed(sessionId, level)`), so when
  the same stackable upgrade (observed: `looter`) rolls at both levels the map
  holds one key with two stacks. Game logic was correct; the assertion was
  seed-dependent.
- Fix: count total stacks (`[...upgrades.entries()].reduce(...)`) instead of
  distinct ids.
- Verification: 8 consecutive `node test/phase4.test.mjs` runs green; full
  `npm run check` + `npm test` 14/14 green.
